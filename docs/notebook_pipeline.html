① 기준선

00CRT 실제 텍스트 응답

목적
Qwen 모델군에 CRT 9문항을 직접 풀게 해, thinking/non-thinking 모드별로 함정에 빠지는지 실측 기준점을 만든다.
입력
crt_behavior_cases() 9문항, CRT_FINAL_ANSWER_SYSTEM_PROMPT(정답 예시 없음, 최종 답 1줄), seed=42.
단계
모델 로드 → 모드별 응답 생성 → thinking 블록/프로토콜/형식 점검 → 정답·함정 라벨 분류 → 정확도 집계.
함수
generate_crt_response_suite, summarize_crt_accuracy, save_qwen_text_responses.
산출물
outputs/00_qwen_crt_text_responses_{dataset}.json과 .md, 모델·모드별 정답률/함정률 표·차트.

② 발견

01Qwen-Scope Activation MVP

목적
NNsight로 residual activation을 뽑고 SAE로 해석해, feature가 가장 강하게 켜지는 layer 후보를 고른다.
입력
5개 프롬프트(bat-ball 등), 프로필별 scan_layers, token 위치 "last".
단계
capture_layer_residuals → SAE 로드 → summarize_qwen_scope_features → scan_qwen_scope_layers로 layer별 점수 → 최고 layer 선택.
산출물
layer별 상위 feature 표(rank, feature_id, mean_abs, activation_rate)와 후보 layer.

02Bat-Ball 단일 feature ablation

목적
bat-ball에서 함정 답 logprob을 끌어올리는 feature를 ablation으로 식별·정량화한다.
입력
instruct_lure_case(BAT_BALL_CASE), 프로필의 두 번째 scan layer, 상위 후보 12개, 계수 1.0.
단계
baseline margin → residual 캡처 → SAE encode 상위 12 → 각 feature decoder direction 제거 후 logprob 재계산 → margin_delta 정렬 → 최고 handle 저장.
함수
answer_logprob_margin, active_prompt_features, rank_lure_feature_effects, save_feature_handle.
산출물
feature별 margin_delta / lure_logprob_delta / correct_logprob_delta 표 + handle JSON.

03Layer sweep feature search

목적
02의 ablation을 프로필의 대표 scan layer 네 곳으로 확장해 가장 큰 영향을 주는 layer-feature 조합을 찾는다.
입력
PROFILE.scan_layers, layer당 상위 8개, 계수 1.0.
단계
각 layer SAE 로드 → layer_feature_search_rows(feature 추출 + ablation + margin) → 정렬 → 최고 handle 저장.
산출물
layer×feature 행 표와, 이후 단계가 공유하는 최종 feature handle.

③ 인과성

04Coefficient dose response

목적
제거 강도(계수)를 바꿀 때 margin이 연속·단조로 변하는지(= 인과) 확인.
입력
저장된 handle, 계수 [-2,-1,-0.5,0,0.25,0.5,1,1.5,2].
함수
load_or_discover_handle_and_sae, coefficient_sweep_for_handle.
읽기
양수 구간 margin_delta 단조 증가 → 강한 인과 근거. 음수에서 반대 효과 → 양방향 steering 가능성.

05Intervention mode comparison

목적
같은 feature에 5가지 개입을 적용해 메커니즘 차이를 비교.
입력
handle, 계수 1.0, 모드 remove_activation / projection_remove / subtract_unit / add_activation / add_unit.
함수
intervention_mode_rows.
읽기
remove·projection 모두 margin 감소 → decoder direction 자체가 중요. add 계열 반대 효과 → steering 신호.

06Control prompt specificity

목적
feature가 함정 논리에 특이적인지, bat/ball 어휘·수식 형식 같은 일반 feature인지 판별.
입력
원 케이스 + matched control(control_prompt, "bat costs $1.05" — 함정 없는 뺄셈).
함수
case_transfer_rows, candidate_feature_rows.
읽기
lure 큰 효과 + control 작은 효과 → 진짜 lure-specific. 둘 다 크면 형식·어휘 일반 feature 의심.

④ 강건성

07Paraphrase robustness

목적
정답/함정은 그대로 두고 문장만 바꾼 paraphrase에서도 효과가 유지되는지(표면 문자열 의존 여부).
입력
bat_ball_paraphrases() (slow, short, Korean, book-toy 등).
함수
instruct_lure_cases, case_transfer_rows.
읽기
original에서만 효과 → overfit 후보. short/Korean/book-toy까지 유지 → 추상적 algebraic-lure feature.

08Answer format sensitivity

목적
효과가 특정 답변 문자열에 묶였는지, 숫자 의미에 작동하는지 검증.
입력
bat_ball_answer_variants() (words / bare number / $0.05 / 문장).
함수
sae_decoder_direction, answer_variant_rows.
읽기
모든 표면형 유사 효과 → reasoning/lure feature. 특정 문자열만 강함 → tokenization·템플릿 효과.

09Token position sweep

목적
feature가 어느 prompt 토큰 위치에서 작동해야 효과가 나는지.
입력
prompt 끝 주변 token window(window≈8~10).
함수
prompt_token_window_rows, token_position_sweep_rows.
읽기
마지막 토큰(Answer:)만 효과 → answer-selection feature. 본문 토큰 효과 → 문제 해석 과정에 관여.

⑤ 일반성·기하

10CRT transfer

목적
bat-ball feature가 구조가 다른 CRT(machines/widgets, lily pads, printers)로 전이되는지.
입력
crt_transfer_cases(), 동일 handle, remove_activation.
함수
crt_transfer_cases, case_transfer_rows.
읽기
산술 CRT만 전이 → 산술 lure feature. 성장·비율까지 전이 → 일반 intuitive-answer feature.

11Control delta bypass

목적
feature를 직접 제거하지 않고, matched control residual과의 차이 벡터를 더해 함정을 우회할 수 있는지.
입력
프로필의 두 번째 scan layer, direction = control_residual − lure_residual, 계수 [-1 … 2], add_vector 모드.
함수
control_delta_bypass_rows.
읽기
양수 계수에서 margin 감소 → matched 표현이 함정 경로를 우회. 음수와 비교해 방향성 확인.

12Decoder geometry

목적
상위 후보들이 비슷한 decoder direction을 갖는지(한 family인가, 서로 다른 경로인가).
입력
프로필의 두 번째 scan layer 상위 12 후보 → 효과 상위 8개.
함수
candidate_feature_rows, rank_lure_feature_effects, decoder_cosine_rows.
읽기
강한 후보끼리 cosine 높음 → 한 feature family. cosine 낮은데 효과 비슷 → 독립 경로.

13Semantic / logic specificity

목적
bat-ball feature가 semantic illusion / logic lure에도 작동하는지(산술 전용인지).
입력
semantic_lure_cases() (Moses ark, widow's sister, affirming the consequent).
함수
semantic_lure_cases, instruct_lure_cases, case_transfer_rows.
읽기
semantic/logic 작음 + CRT 큼 → 산술 도메인 특이. 전반적으로 크면 일반 caution/lure-suppression 계열.
